# AI ARCHITECT & FULL-STACK DEVELOPER PROMPT: INTERACTIVE BLOG BUILDER & BLOCK EDITOR

## CORE OBJECTIVE
You are an expert full-stack developer specializing in interactive web applications and rich text canvas editors. You are helping me build a modern **Blog Creation Page (`/blogs/new`)** for my blogging platform.

This page allows users to author blog posts using a visual, modular, drag-and-drop block editor. Users can add custom text boxes, format rich text, customize typography, upload images, and configure page-level interactivity such as scroll transitions.

---

## FEATURE SPECIFICATIONS

### 1. Drag-and-Drop Canvas & Block System
- **Drag-and-Drop Interface**: Allow users to drag blocks onto a dynamic canvas and reorder existing blocks smoothly (e.g., using `@hello-pangea/dnd`, `dnd-kit`, or Framer Motion).
- **Available Block Types**:
  - `Heading Block` (H1, H2, H3 with custom font selection)
  - `Rich Text Block` (WYSIWYG editor supporting bold, italic, underline, strike, bullet points, numbered lists, blockquotes, and hyperlinks via TipTap or Slate.js)
  - `Custom Text Box` (A styled container box with customizable background color, border radius, padding, and text)
  - `Image Block` (Supports drag-and-drop file upload, URL input, image captioning, and alignment controls)
  - `Spacer / Divider Block` (Horizontal line or adjustable vertical spacing)

### 2. Styling & Typography Controls
- **Font Selector**: Allow users to choose custom fonts (e.g., Google Fonts like Inter, Playfair Display, Merriweather, Roboto, Fira Code) applied globally or to individual text blocks.
- **Color & Size Picker**: Text color, background color, and font sizing controls per block.

### 3. Interactivity & Scroll Transition Engine
- Provide a **Page Settings Panel** where the author can toggle and choose scroll transitions applied when readers view the published blog post:
  - `Fade In Up`: Blocks fade and translate upward as they enter the viewport.
  - `Scale / Zoom`: Blocks smoothly scale from 90% to 100% size on scroll.
  - `Parallax Effect`: Subtle relative scroll speed differences for image blocks.
  - `Slide In`: Blocks enter from left/right margins.
- Implement these scroll effects clean and performantly (e.g., using `Framer Motion` with `whileInView` or Intersection Observer).

### 4. Blog Publishing Data Schema
Ensure the blog JSON structure stores block order, content, styles, and animation metadata:

```json
{
  "title": "My Interactive Blog Post",
  "slug": "my-interactive-blog-post",
  "global_font": "Playfair Display",
  "scroll_transition": "fade_in_up",
  "blocks": [
    {
      "id": "block-1",
      "type": "heading",
      "content": "Welcome to my story",
      "styles": { "level": 1, "font": "Playfair Display", "align": "center" }
    },
    {
      "id": "block-2",
      "type": "custom_text_box",
      "content": "Key takeaways box with custom styling",
      "styles": { "backgroundColor": "#f3f4f6", "borderColor": "#3b82f6", "borderRadius": "8px" }
    },
    {
      "id": "block-3",
      "type": "image",
      "content": { "url": "https://storage.yourapp.com/blog/img1.webp", "caption": "Scenic landscape" },
      "animation": { "parallax": true }
    }
  ]
}
```
